첫 화면의 그림은 고객의 서비스 이용, 관리자의 지식 개선, 운영자의 배포·관측·복구를 함께 설명합니다. 별도의 고객 상담 안내 그림에서는 질문에 답하는 과정과 고객 요청에 따른 상담사 연결, 미응답 개선 과정을 확인할 수 있습니다.

처리 흐름도는 SVG로 작성하고 PNG로 렌더링했습니다. 분홍·보라 강조색과 여백을 제품 화면에 맞췄으며, 한글은 FE에서 사용하는 SUITE 글꼴로 렌더링했습니다. SVG 원본은 시스템 글꼴로도 열 수 있습니다. 모바일 그림은 단계들을 세로로 배치해 작은 화면에서도 글자를 읽을 수 있게 했습니다.
