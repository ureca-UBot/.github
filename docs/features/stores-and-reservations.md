# 매장 찾기에서 방문 예약까지

[전체 기능](../README.md) · [상품과 이용 정보](products-and-subscriptions.md) · [알림](customer-support.md)

고객은 가까운 매장을 찾고 경로와 방문 시간을 확인한 뒤 예약합니다. 검색·지도·길찾기·예약을 같은 이용 흐름으로 연결합니다.

## 방문을 준비하는 흐름

| 고객 행동 | FE가 하는 일 | BE가 하는 일 | 고객이 확인하는 결과 |
|---|---|---|---|
| 매장 찾기 | 검색어·지역·서비스 조건 또는 지도 범위 전달 | 조건과 공간 범위에 맞는 매장 조회 | 목록과 지도 위 매장 위치 |
| 내 주변 찾기 | 브라우저 위치 권한을 확인해 좌표 전달 | 현재 위치 주변의 매장 조회 | 가까운 매장과 거리 |
| 길찾기 | 출발지·목적지와 이동 방식 선택 | 경로 제공 기능과 연결해 이동 자료 반환 | 도보·자동차·대중교통 경로 |
| 방문 예약 | 날짜별 가능 시간을 조회하고 선택 시간 요청 | 영업 시간·예약 가능 기간·중복·본인 한도 확인 | 확정 예약 또는 충돌·제한 안내 |
| 취소·내역 확인 | 본인 예약 조회와 취소 요청 | 소유권·예약 상태·시간 조건을 확인해 처리 | 갱신한 상태와 관련 알림 |

## 검색 결과를 방문까지 이어갑니다

지도 영역을 이동하거나 검색 조건을 바꾸면 목록을 다시 불러옵니다. 위치 권한을 허용하지 않아도 지역·주소·매장명으로 찾을 수 있습니다. AI 상담에서 찾은 매장도 카드와 지도 자료로 확인할 수 있습니다.

예약 가능한 시간 목록을 봤더라도 확정 전에 다른 고객이 같은 시간을 예약할 수 있습니다. 서버는 저장할 때 다시 중복과 예약 조건을 확인합니다. 화면은 성공 응답을 받은 예약만 확정으로 보여 줍니다.

관리자는 매장 정보와 예약 목록을 확인하고 방문 완료·미방문·취소 상태를 처리합니다. 예약·취소·방문 전 알림은 고객이 진행 상태를 다시 확인하도록 돕습니다.

## 실패했을 때

위치 권한 거절, 경로 조회 실패, 예약 충돌은 서로 다른 상황입니다. 고객은 위치 입력이나 조회·시간 선택을 다시 할 수 있습니다. 실패한 요청을 예약 성공으로 처리하거나 길찾기 결과를 임의로 만들지 않습니다.
